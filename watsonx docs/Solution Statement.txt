SOLUTION STATEMENT - AI-Powered Expense Tracker (IBM watsonx Challenge)
Software Track

THE PROBLEM
Receipts arrive in incompatible formats — phone photos, scanned PDFs, bank-statement
exports, and CSV files — and no affordable tool bridges all of them into a single
structured, searchable record without manual data entry.

THE SOLUTION
Drop any receipt into the browser. An all-IBM AI pipeline reads the document,
extracts each line item (date, merchant, amount, currency), assigns a category,
and stores the result. A React + Tailwind CSS dashboard shows a spend-by-category
bar chart, totals, and separate expense and deposit tables — all scoped to the
logged-in user.

HOW IT WORKS FOR THE USER
1. Register or log in (email/password, JWT-secured session).
2. Upload a receipt image, bank-statement PDF, or CSV.
3. Extracted, categorized rows appear immediately on the dashboard.
4. Search in plain English: "groceries from July 1st to 15th" — the app returns
   a filtered summary and matching rows.
5. Correct a category once and the app learns: the choice is remembered for that
   merchant and applied automatically to future uploads.

WHY IT MATTERS
This is a deployable SaaS product, not a proof-of-concept. Each user's data is
fully isolated at every layer — JWT auth, per-user Cloudant selectors, and per-user
COS namespacing. The merchant learning loop means the product improves with use:
one correction teaches the system, so every future receipt from that merchant is
categorized correctly without prompting.

BUILT ENTIRELY ON IBM
- watsonx.ai (Llama 3.2 Vision) — OCR of image and scanned-PDF receipts.
- watsonx.ai (Granite 3 Instruct) — categorization, normalization, NL query.
- IBM Cloudant — per-user expense records.
- IBM Cloud Object Storage — original uploaded files, namespaced per user.
- IBM Code Engine — target single-container deployment platform.

Privacy is built in: deposit amounts are obfuscated before storage and display.

DEPLOYMENT STATUS
Production-ready: a multi-stage Dockerfile builds and serves the full stack from
a single container; IBM Code Engine deploy commands are in web/README.md with
secrets injected at runtime. A live URL requires a Pay-As-You-Go account; all
artefacts are in the repo and verified locally.

In short: snap a photo of a receipt, and watsonx.ai turns it into an organized,
searchable, self-learning view of your money — all on IBM Cloud.
